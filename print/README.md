# Current print files

Use **[V25 — seating trial and PETG print-quality project](v25_quality/README.md)** for the latest controller-cover trial, separate plates and anti-stringing starting settings. Print its plate 1 before committing to the full mount. Exact OEM fit remains unverified.

[V24](v24_iemai_petg/README.md) is retained for history; its extended clips were reported not to seat fully. V25 retains V24's box/lid geometry and keyless interface.

The loose STLs in this directory and `u1_black_pla/` are the archived V23 design. They do not include the V24 fit corrections. `originals/` in the repository root preserves the supplied V22 files.
