# Current print files

Use **[V24 — IEMAI matte PETG on Snapmaker U1](v24_iemai_petg/README.md)** for the revised box cavity, matching sliding cap, thinner/longer controller clips and keyless dock. Its 3MF includes the saved material settings, print orientations and custom supports.

The loose STLs in this directory and `u1_black_pla/` are the archived V23 design. They do not include the V24 fit corrections. `originals/` in the repository root preserves the supplied V22 files.
