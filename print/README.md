# Current print files

Use **[V26 — controller retention trials](v26_retention/README.md)**. Start with cover A in the small two-cover 3MF, then print the matching full mount only after checking physical fit. V26 retains V25 PETG print settings and the shared box/lid.

[V25](v25_quality/README.md) seated better but was reported to release under a slight backward pull. [V24](v24_iemai_petg/README.md) did not seat fully. Both remain available for history.

The loose STLs in this directory and `u1_black_pla/` are the archived V23 design. `originals/` in the repository root preserves the supplied V22 files.
